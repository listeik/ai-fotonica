# План реализации

На момент начала работ локальный каталог и `origin` не содержали коммитов. Настройки IDE остаются локальными. Численные параметры и формат файлов сверены с заданием «Хакатон_задача_q2.docx» и презентацией «AI фотоника.pdf» лаборатории НИЯУ МИФИ. Условие требует сохранять модули комплексного поля, поэтому экспортируем амплитуду.

1. Реализовать оператор Френеля и сверить комплексное поле с прямым дискретным интегралом. Проверить градиенты, масштаб и PNG.
2. Зафиксировать классическую оптимизацию и общий критерий сравнения. Обучить U-Net через тот же оператор, начиная с проверки переобучения малой выборки.
3. Сравнить один проход сети, классический Adam и уточнение фазы из сети на отложенных наборах. Везде оценивать восстановление из экспортированного ДОЭ.
4. Подключить алгоритмы к FastAPI и React, проверить загрузку четырёх целей, скачивание ДОЭ и экспорт сравнения.
5. Сохранить конфигурацию, веса, метрики, описание ограничений и инструкции воспроизведения. Проверенные изменения отправлять в `feat/doe-neural-synthesis`.
