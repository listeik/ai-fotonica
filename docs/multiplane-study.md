# Сравнение двух сетей для четырёхплоскостного синтеза ДОЭ

## Архитектуры и основания

**Fresnel U-Net Projection v2** предсказывает амплитуду и фазу поля на каждой плоскости. Сеть обратно распространяет и суммирует поля на сетке ДОЭ, затем применяет три фиксированных обучаемых проекционных слоя. Они входят в один `forward` и задают его вычислительную стоимость.

**Physics-Informed Multi-plane Residual Fourier U-Net** начинает с обратного распространения четырёх амплитуд с той же фиксированной фазовой кодировкой. Из суперпозиции получается пробный фазовый ДОЭ. Одно распространение пробного поля даёт четыре комплексных поля. Для каждой плоскости вычисляется невязка `(sA − |U|) · exp(i arg U)`, где `A` — целевая амплитуда с небольшой положительной добавкой, а `s` согласует L2-нормы `A` и `|U|`. Обратное распространение переводит четыре невязки на сетку ДОЭ. Их среднее корректирует опорный фазор. U-Net получает 14 каналов: четыре цели, две компоненты опорного фазора и восемь компонент невязок. На сетке 16×16 в узком месте сети глубинный спектральный фильтр с обучаемыми комплексными весами и последующей свёрткой 1×1 добавляет глобальную поправку к локальным признакам. Выход сети поворачивает опорный фазор и возвращает одну карту фазы.

DeepCGH использует дифракционную модель в функции потерь и фиксированную вычислительную схему для синтеза многоплоскостных фазовых голограмм. TensorHolo v2 показывает применение физических операций и ошибки фокусного стека при обучении фазового кодирования. Отсюда взяты идеи общей физики в обучении и совместной оценки всех глубин. [Eybposh et al., Optics Express, 2020](https://par.nsf.gov/servlets/purl/10301962), [Shi et al., Light: Science & Applications, 2022](https://cdfg.mit.edu/assets/images/3d-phase-only-holograms.pdf)

В работах Neural 3D Holography и Zeng et al. межплоскостное распространение и подавление паразитного сигнала оцениваются с учётом оптической установки. Здесь оценивается доля мощности на тёмном фоне в симуляции. Эта метрика включает вклад рассеянного света от других глубин и не разделяет его по источникам. [Choi et al., SIGGRAPH Asia, 2021](https://www.computationalimaging.org/wp-content/uploads/2021/08/NeuralHolography3D.pdf), [Zeng et al., Photonics, 2026](https://doi.org/10.3390/photonics13030252)

Обучаемый множитель в частотной области основан на идее Fourier Neural Operator. В этой реализации фильтр действует поканально на признаках U-Net, а переход между каналами выполняет свёртка 1×1. Проверяется вся архитектура целиком, поэтому сравнение не изолирует эффект спектрального блока. [Li et al., ICLR, 2021](https://arxiv.org/abs/2010.08895)

## Протокол

- Одинаковая одно-FFT модель Френеля, `128×128`, длина волны 532 нм, шаг пикселя ДОЭ 10 мкм, расстояния 24,1, 25,3, 26,5 и 27,7 мм. Предполагается плоская падающая волна единичной амплитуды. Цели задают амплитуду, каждая плоскость имеет собственную сетку Френеля.
- Обе модели обучаются с нуля на одних 256 стеках `procedural-v1`. Валидация использует 32 отдельных стека. Seed датасета 2026 фиксирован. Для пар запусков с seed 2026, 2027 и 2028 совпадают порядок мини-батчей, Adam, размер батча 8, скорость обучения 0,001 и функция потерь. Через квантование фазы на 256 уровней градиент передаётся методом straight-through. Целевая функция складывает MSE амплитуды, `0,4 × (1 − PCC)`, `0,2 × (1 − SSIM)` и `0,12 × утечка`. Сохраняется лучшая эпоха по этой же функции на валидации.
- Основной бюджет составляет шесть эпох и 192 обновления на архитектуру для каждого seed. Дополнительный контроль времени даёт Fourier-модели восемь эпох и 256 обновлений при тех же данных. Длительность выбрана по времени первой пары запусков до оценки тестов. Регистрируется суммарное время обучающих батчей, включая загрузку готовых батчей и обновление весов. Подготовка датасета, валидация и запись весов в этот бюджет не входят.
- Тест включает 128 отдельных синтетических стеков. Для проверки переноса взяты по 96 стеков из официальных тестовых частей MNIST и Fashion-MNIST. Каждый стек использует четыре уникальных исходных изображения на разных глубинах. Внутри каждого датасета изображения не повторяются. Исходные изображения приведены к 84×84 билинейной интерполяцией и дополнены чёрной рамкой до 128×128. Индексы и хеши архивов записаны в манифесте. [MNIST, LeCun et al.](https://archive.ics.uci.edu/dataset/683/mnist+database+of+handwritten+digits), [Fashion-MNIST, Xiao et al.](https://research.zalando.com/publication/fmnist_2017/)
- PCC и SSIM считаются после квантования фазы и округления нормированной по пику амплитуды до 8 бит, с окном SSIM 7×7. Утечка равна сумме `|U|²` на пикселях цели с амплитудой ≤ 2/255, делённой на суммарную мощность плоскости до нормировки. Четыре плоскости, стеки и seed усредняются с равными весами.
- Время инференса измеряется для одного стека, от готового входного тензора до квантованной фазы. Для каждой модели проводится 20 прогревочных и 100 измеряемых вызовов, порядок моделей перемешивается в каждом раунде. Реконструкция и запись PNG вне измеряемого интервала. Обе модели синтезируют фазу одним вызовом без внешней итеративной оптимизации, перебора стартов или подбора результата.
- Основной критерий выбора — среднее `PCC + SSIM − утечка` на двух внешних датасетах с равными весами. Сравнение парное по seed обучения и стекам. 95%-й процентильный интервал получен из 10 000 бутстрэп-выборок с ресэмплингом пар seed и целых стеков. Архитектура выигрывает, если интервал исключает ноль и знак одинаков во всех трёх парах. В случае противоположных решений при двух бюджетах результат считается зависимым от бюджета. Время и отдельные метрики приводятся рядом с составным критерием. Выпущенный ранее чекпойнт оценивается для справки и исключён из парного сравнения.

## Воспроизведение

```powershell
python -m pip install -e ./backend
python -m doe.training.multiplane_study train --config configs/multiplane-study.json --output runs/multiplane-main --device cpu
python -m doe.training.multiplane_study train --config configs/multiplane-study.json --output runs/multiplane-time --device cpu --model residual-fourier --epochs 8
python -m doe.training.multiplane_evaluate evaluate --study runs/multiplane-main --cache runs/multiplane-data --published artifacts/doe-unet.pt
python -m doe.training.multiplane_evaluate evaluate --study runs/multiplane-main --fourier-study runs/multiplane-time --cache runs/multiplane-data
```

Восстановить фазовый PNG можно из любого сохранённого чекпойнта. Четыре входных PNG должны быть 8-битными полутоновыми `128×128` и идти по возрастанию глубины.

```powershell
python -m doe.training.multiplane_evaluate synthesize --checkpoint runs/multiplane-main/residual-fourier-2026/best.pt --targets plane1.png plane2.png plane3.png plane4.png --output doe.png
```
