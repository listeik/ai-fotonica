# Обучение отдельной модели синтеза ДОЭ на GPU

Эксперимент обучает новый чекпойнт с нуля. Архитектура использует существующий Fresnel U-Net Projection v2: ширина 16, шесть обучаемых проекционных слоёв, положительная добавка к амплитуде 0,01. В модели 483 030 параметров. Выход — одна фазовая карта 128×128 для четырёх целевых амплитуд. Чекпойнт совместим с `doe.models.load_model` и существующим CLI проекта.

Параметры зафиксированы в `configs/photo-model.json`. Обучение выполняется на NVIDIA GeForce RTX 3050 Ti Laptop GPU, PyTorch 2.7.1+cu128, CUDA 12.8. Используется отдельная локальная CUDA-сборка из `runs/cuda/runtime`; CPU-сборка в основном виртуальном окружении сохранена.

Первый этап включает четыре эпохи на всех 16 000 наборах `train` широкого датасета `doe-dataset-v1`. На каждой эпохе порядок изображений по фокальным плоскостям случайно меняется. Второй этап использует до двадцати эпох по 1280 наборов. В 75% случаев случайно выбираются четыре разных человека из 32 обучающих людей Olivetti и по одному кадру каждого. Остальные 25% — повторение случайных широких обучающих наборов. Новая комбинация кадров также задаёт новую обратную задачу, которая оценивается прямой физической моделью. Исходные найденные итеративные ДОЭ в обучение не входят.

В обоих этапах AdamW обновляет веса через квантование фазы и амплитуды до 8 бит с прямой передачей градиента. Функция потерь равна сумме `1 − средний PCC`, `1 − средний глобальный SSIM`, четверти суммы соответствующих ошибок худшей плоскости каждого набора, `0,1 × MSE` и `0,05 × доля мощности на тёмном фоне`. PCC и глобальный SSIM определены явно в `people_doe_reference.py`. Тёмный фон означает значение цели не выше 2/255.

Валидация содержит 128 заранее выбранных широких наборов и 10 портретных наборов четырёх отдельных людей. Критерий выбора чекпойнта — `0,7 × (PCC + глобальный SSIM) портретов + 0,3 × (PCC + глобальный SSIM) широких целей`. Средние берутся по изображениям и наборам соответствующей группы. Этот критерий фиксирован для обоих этапов. Второй этап останавливается после семи эпох без улучшения. По тому же валидационному критерию выбирается лучший из двух этапов.

Контрольное сравнение оценивает новую модель, прежнюю Residual Fourier и прежнюю Projection v2 на одних целях: 10 портретных наборов ещё четырёх людей, 128 широких тестовых наборов и 64 независимых OOD-набора. Ни тест, ни OOD не участвуют в вычислении градиента и выборе эпохи. Короткий предварительный запуск проверял работоспособность всего конвейера, включая оценку. Полная конфигурация была зафиксирована до него; параметры по его тестовым результатам не подбирались.

При сравнении все три модели получают один вызов `forward` на GPU. Затем фаза экспортируется в PNG, читается обратно и на CPU рассчитывается восстановление, которое также проходит через 8-битный PNG. По этим пикселям считаются PCC, глобальный SSIM, отдельный локальный SSIM с окном 7×7 и MSE. Внешний итеративный поиск при оценке отсутствует. Метрики отражают симуляцию Френеля, а не измерение оптической установки.

Это практическое сравнение чекпойнтов с разными объёмами данных, числом параметров и бюджетами обучения. Оно не изолирует влияние изменения архитектуры. Один новый запуск не даёт оценки разброса между seed. Значения `worst_pcc` и `worst_ssim` в групповой сводке являются средними минимумов четырёх плоскостей отдельных наборов; метрики каждой плоскости и каждого набора доступны в полном `evaluation.json`.

Портреты — 400 кадров 40 людей исходного разрешения 64×64, увеличенных до 128×128. Все десять кадров одного человека принадлежат одной выборке. Проверка источников не приравнивает 400 разных кадров к 400 разным людям. Итоговые портретные тесты ограничены четырьмя отложенными людьми. Происхождение и условия использования данных описаны в `docs/people-doe-100/README.md` и исходных манифестах.

Код подготовки проверяет формат и контрольные суммы выбранных изображений, совпадения пикселей между выборками и разделение людей. Для широкого датасета SHA-256 в CSV относится к массиву пикселей; для портретного — к PNG-файлу. Результаты проверки и точные индексы выборок сохраняются в `data.json`.

## Полученные результаты

Выполнены все четыре общие и двадцать портретных эпохи: 5600 обновлений AdamW, 89 600 предъявлений наборов. Обучение с подготовкой кэша и валидацией заняло 644,4 с. Пиковая память тензоров CUDA составила 832,1 МиБ. По валидации выбрана эпоха 18 второго этапа, чекпойнт после 5440 обновлений. Все числа ниже относятся к этой версии, а не к последней эпохе.

| Проверка | Модель | Средний PCC | Глобальный SSIM | Локальный SSIM 7×7 |
| --- | --- | ---: | ---: | ---: |
| Портреты, 10 наборов | Прежняя Fourier | 0,3162 | 0,2817 | 0,0940 |
| Портреты, 10 наборов | Прежняя Projection | 0,4287 | 0,3724 | 0,1247 |
| Портреты, 10 наборов | **Новая** | **0,5593** | **0,4612** | **0,1645** |
| Разнообразные цели, 128 наборов | Прежняя Fourier | 0,2826 | 0,2079 | 0,1094 |
| Разнообразные цели, 128 наборов | Прежняя Projection | 0,3495 | 0,2564 | 0,1382 |
| Разнообразные цели, 128 наборов | **Новая** | **0,4424** | **0,3178** | **0,1750** |
| OOD, 64 набора | Прежняя Fourier | 0,3000 | 0,2297 | 0,1509 |
| OOD, 64 набора | Прежняя Projection | 0,3742 | 0,2854 | 0,1841 |
| OOD, 64 набора | **Новая** | **0,4787** | **0,3509** | **0,2217** |

Новая модель повысила все три средние метрики относительно обоих прежних чекпойнтов на каждой из трёх тестовых групп. **Порог 0,9 не достигнут:** число наборов с PCC и глобальным SSIM выше 0,9 на всех четырёх плоскостях равно нулю. Восстановления сохраняют заметный шум, что отражено низкими значениями локального SSIM. Для ориентира, ранее сохранённые итеративные ДОЭ на тех же десяти портретных наборах имеют средние PCC 0,6766, глобальный SSIM 0,6419 и локальный SSIM 0,2495. Они не являются сетевым предсказанием и не использовались при обучении.

Медиана времени одного `forward` на GPU составила 8,94 мс для новой модели, 5,75 мс для прежней Projection и 4,20 мс для Fourier. Это отдельный последовательный замер одного набора, десять прогревов и пятьдесят повторений, с синхронизацией CUDA. Он исключает ввод-вывод и физическое восстановление PNG; порядок моделей фиксирован, поэтому значения являются ориентиром задержки в этой сессии.

Сохранены веса `runs/photo-model-v1/best.pt`, полный отчёт `evaluation.json`, примеры `preview.png`, графики `learning-curves.png` и `comparison.png`. Копия весов включена в репозиторий как `artifacts/doe-photo-projection-v1.pt`. Веса занимают 2 211 558 байт, SHA-256: `527142714a0da4a92c3293e95f54846a6573fc0931a6335727ef6a6926cd1f2b`. Рядом с этим документом находятся сводные метрики, конфигурация, история эпох, сведения об окружении, контрольные суммы кода и описание выборок. В копии `data.json` для Git непрерывные индексы обучения 0–15999 представлены диапазоном с исключённой правой границей; выбранные индексы остальных групп перечислены явно.

Проверены полный короткий запуск конвейера на GPU и 18 тестов физики, обучения и синтеза. Полученный чекпойнт также проверен обычным CLI на GPU и CPU: максимальное различие четырёх агрегированных PCC/SSIM относительно контрольного отчёта для первого тестового набора меньше 0,000035. PNG и большие кэши остаются в локальном каталоге `runs/`.

Повторное физическое восстановление всех 30 сохранённых портретных предсказаний трёх моделей подтвердило точное совпадение 150 PNG и всех записанных метрик. Проверены также контрольные суммы кода и чекпойнта; результаты находятся в `integrity.json`.

## Запуск

Из корня проекта с уже подготовленными данными:

```powershell
$env:PYTHONPATH = (Resolve-Path 'runs/cuda/runtime').Path
.venv/Scripts/python.exe backend/scripts/train_photo_doe.py --config configs/photo-model.json --output runs/photo-model-repeat --device cuda
```

Выходной каталог должен быть новым. В нём сохраняются `best.pt`, лучшие и последние веса каждого этапа, журналы эпох, конфигурация, описание выборок, окружение, полный отчёт `evaluation.json` и PNG-примеры для всех десяти портретных тестовых наборов. Кэш `cache/` содержит только исходные цели в uint8 для ускорения загрузки. Новые веса сохраняются отдельно от чекпойнтов `artifacts/`, обслуживающих приложение.

Пример использования полученных весов через существующий CLI:

```powershell
.venv/Scripts/python.exe -m doe --method neural --checkpoint artifacts/doe-photo-projection-v1.pt --device cuda --output runs/photo-model-inference runs/people-doe-100-v1/test/000/target-1.png runs/people-doe-100-v1/test/000/target-2.png runs/people-doe-100-v1/test/000/target-3.png runs/people-doe-100-v1/test/000/target-4.png
```
