# Модель распространения

Рассматриваем равномерную плоскую волну, квадратную апертуру без дополнения нулями и скалярное параксиальное приближение. ДОЭ задаёт поле `U₀ = exp(iφ)`. Расстояния в коде выражены в метрах.

Для размера `N`, шага модулятора `d` и расстояния `z` сетка входа задаётся как `(j − floor(N/2)) · d`, а шаг выхода равен `d′ = λz / (N d)`. Для четырёх расстояний шаги выхода составляют примерно 10.0166, 10.5153, 11.0141 и 11.5128 мкм. Изображение цели сопоставляется с нативной сеткой каждой плоскости по индексам пикселей.

Один FFT вычисляет дискретный интеграл Френеля для каждой плоскости:

```text
U_z(x′, y′) = exp(ikz)/(iλz) · exp(iπ(x′² + y′²)/(λz))
              · d² · centeredFFT[U₀(x,y) · exp(iπ(x²+y²)/(λz))]
```

`centeredFFT` реализован как `fftshift(fft2(ifftshift(...)))` по двум пространственным осям без нормировки прямого FFT. Множитель `d²` соответствует площади входной ячейки. Для расчёта модуля выходной фазовый множитель можно опустить. Обратный оператор делит на выходной множитель, выполняет центрированный IFFT и снимает входную фазу отдельно для каждой плоскости.

Численная проверка сравнивает комплексное поле с прямой суммой ядра `exp(iπ((x′−x)²+(y′−y)²)/(λz))` на чётной и нечётной сетках. Дополнительно проверяются фокус линзы, энергия с учётом площадей ячеек, обратное распространение и градиент. Формула согласуется с заданием и [лекцией MIT по дифракции Френеля](https://ocw.mit.edu/courses/2-71-optics-spring-2014/e6c5af8e2e9757e569fdc7c76cd623aa_MIT2_71S14_lec20_notes.pdf).

Фазу округляем до ближайшего из 256 уровней от −π до +π. Экспортное восстановление всегда стартует с декодированных пикселей этого PNG. Амплитуда `abs(U_z)` каждой плоскости делится на её максимум, если он ненулевой, и округляется до восьми бит. PCC и SSIM сравнивают полученные пиксели с исходными целями; правило нормировки одинаково для всех методов. Для постоянного изображения PCC определён в отчёте как 0. SSIM считается по всему изображению в диапазоне [0, 1]: `((2μxμy + c1)(2cov(x,y) + c2)) / ((μx² + μy² + c1)(var(x) + var(y) + c2))`, где `c1 = 0.01²`, `c2 = 0.03²`. Дисперсии и ковариация используют среднее по всем пикселям с делением на N. Та же формула используется при обучении и итеративном уточнении. Ранее сохранённые отчёты использовали локальный SSIM с окном 7×7 и требуют пересчёта для сравнения с новыми метриками.

Эти тесты проверяют численный оператор в принятой модели. Они не оценивают физический ПВМС, аберрации, освещение реального лазера или оптическую эффективность.
