# Уточнение фазового ДОЭ

Команда `doe.refine` принимает готовый фазовый PNG и четыре исходные цели. Она меняет фазу, рассчитывает поля заново и сохраняет новый ДОЭ, четыре реконструкции и `metrics.json` с измерениями до и после.

1. Передайте цели в порядке 24,1, 25,3, 26,5 и 27,7 мм. Укажите новый выходной каталог.

   ```sh
   python -m doe.refine --phase current-doe.png --output runs/refined z1.png z2.png z3.png z4.png
   ```

2. Сравните PCC, SSIM и доли мощности по каждой плоскости. При необходимости сравните с таким же числом шагов обычного Adam, передав `--background-weight 0 --ghost-weight 0 --shape-weight 0`.
3. Если важнее убрать засветку, попробуйте `--background-weight 0.20 --ghost-weight 0.10 --shape-weight 0` с тем же входным ДОЭ. Если важнее сохранить форму на всех четырёх плоскостях, начните со сбалансированных настроек по умолчанию.

## Функция потерь

Текущая функция потерь сравнивает нормированную амплитуду с целью через MSE, PCC и локальный SSIM. Уточнение добавляет к ней три слагаемых.

```python
loss = reconstruction_loss(amplitude, target, pcc_weight=0.40)
loss += 0.08 * background_power.mean()
loss += 0.04 * ghost_region_power.mean()
loss += 0.70 * (1 - cosine_similarity(amplitude.flatten(1), target.flatten(1), dim=1).mean())
```

- Для фона берём долю мощности `|U|²` в пикселях цели со значениями до `2/255`. Считаем по каждой плоскости до нормировки яркости.
- Для областей возможных помех переносим маски двух ближайших плоскостей на физическую сетку текущей плоскости. Берём объединение, исключаем собственный объект с запасом в два пикселя и измеряем долю мощности под этой маской. Это индикатор засветки в области ожидаемых силуэтов. Когерентное поле содержит интерференцию, поэтому по этому числу нельзя выделить вклад конкретной плоскости.
- Косинусное слагаемое сравнивает форму амплитуды без привязки к одному самому яркому пикселю.

Adam делает 60 шагов с `lr=0.08`. На каждом шаге прямой проход использует квантованную фазу, а градиент проходит к непрерывному параметру. Выбирается фазовая карта с минимальной целевой функцией среди начальной фазы и всех шагов. Фоновые маски используются внутри функции потерь. Сохранённые реконструкции целиком получены из Френеля после декодирования итогового фазового PNG.

## Проверка на трёх наборах

Использованы 12 ранее подготовленных целей из трёх наборов (геометрия, символы, контуры с градиентами). Каждый вариант получил один и тот же исходный **8-битный** фазовый PNG от модели `695e8ba93292` для каждого набора. Параметры уточнения проверялись на этих же целях, поэтому результаты описывают этот батч.

| Вариант | Средний PCC | Средний SSIM | Мощность в фоне | Мощность в областях силуэтов |
|---|---:|---:|---:|---:|
| Исходный Neural | 0,6346 | 0,0614 | 45,91% | 21,38% |
| Текущая функция, 60 шагов | 0,6421 | 0,2916 | 43,04% | 20,86% |
| Сбалансированная, 60 шагов | 0,6457 | 0,3154 | 39,26% | 20,37% |
| Усиленные маски, 60 шагов | 0,5926 | 0,5191 | 32,75% | 15,93% |

Сбалансированный вариант уменьшил обе абсолютные доли мощности и немного улучшил обе средние метрики при том же бюджете. Усиленные маски снизили мощность в областях силуэтов на 4,93 процентного пункта, но дали меньший PCC. Ни один из вариантов не достиг 0,9 по обеим метрикам. В отдельной диагностике синтез каждой цели по отдельности за 200 шагов дал средние PCC 0,970 и SSIM 0,273. Высокий одноплоскостной PCC показывает влияние совместного синтеза на корреляцию. Низкий одноплоскостной SSIM показывает, что оптимизации фона и формы всё ещё есть куда расти даже в этом контроле.

## Следующие эксперименты

1. На отдельном валидационном батче сравнить бюджеты 60, 120 и 200 шагов. Для длинного прогона проверить `lr=0.04` со спадом до `0.005`. Выбирать параметры по средним и худшим PCC/SSIM и мощности фона, особенно для символов.
2. Если ошибки сосредоточены на узких контурах, отдельно проверить MSE с равным вкладом переднего плана и фона или L1 на градиентах Собеля. Сравнить с косинусным штрафом при тех же фазе и бюджете.
3. Для дообучения перенести измеренные фоновые штрафы в обучение U-Net и отдельно сравнить текущий амплитудный порог `target + 0.03` с `target + 0.005` в тёмных областях. Начать с текущих весов, `lr=1e-4` и 10–20 эпох. Для полностью чёрной цели сохранить защиту от нулевой энергии. Дополнительные проекционные слои имеет смысл оценивать отдельным прогоном.
