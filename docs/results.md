# Результаты синтеза ДОЭ

Итоговые веса [doe-unet.pt](../artifacts/doe-unet.pt) получены на NVIDIA GeForce RTX 3050 Ti Laptop GPU с PyTorch 2.7.1 и CUDA 12.8. Модель версии `fresnel-unet-projection-v2:695e8ba93292` выбрана до итогового теста по общей ошибке восстановления на 32 валидационных наборах. Чекпойнт содержит 1 152 шага обучения; SHA-256: `695e8ba932927602c0f3968a78391bcbd77c79f0c8c23671583fc4a41636587f`.

## Обучение и выбор модели

Генератор `procedural-v1` создал 768 обучающих наборов, по четыре изображения в каждом. Он варьирует геометрию, положение, масштаб, толщину контуров и яркость объектов; в выборке есть фигуры, символы и полутоновые цели. Валидация, контрольный тест и демо используют отдельные потоки генератора с фиксированным seed 2026.

| Прогон | Ошибка до → после | PCC до → после | SSIM до → после |
|---|---:|---:|---:|
| 30 шагов на тех же 4 обучающих наборах | 0,437 → 0,392 | 0,497 → 0,550 | 0,039 → 0,149 |
| U-Net, 24 эпохи, валидация | 0,434 → 0,410 | 0,509 → 0,516 | 0,038 → 0,157 |
| U-Net и три слоя проекции, 12 эпох, валидация | 0,390 → 0,377 | 0,601 → 0,622 | 0,053 → 0,063 |

Первый прогон проверяет, что сеть может уменьшать ошибку, и не измеряет обобщение. Значения в эпохе 0 уже отражают вклад физического оператора; разница с последней строкой журнала показывает вклад обучения внутри каждой архитектуры. Три слоя проекции улучшили валидационный PCC и общий критерий, при этом базовая U-Net лучше по SSIM. В выбранной архитектуре каждый слой согласует комплексное поле с предсказанной амплитудой цели, переносит его обратно в плоскость ДОЭ и обновляет фазу. Вес каждой плоскости и долю обновления сеть учит вместе со свёртками. Neural выполняет все три слоя в одном проходе без обратного распространения градиента на этапе синтеза.

Журналы: [контрольное обучение](../experiments/training/overfit.jsonl), [базовая U-Net](../experiments/training/base.jsonl), [модель со слоями проекции](../experiments/training/projected.jsonl).

## Сравнение на отложенной выборке

32 набора, 128 плоскостей, одинаковые цели и устройство для всех методов. Метрики рассчитаны по PNG восстановления из 8-битного ДОЭ. Время — медиана синтеза после прогрева; кодирование PNG, загрузка весов и вычисление метрик измерением не охватываются.

| Метод | Средний PCC | Средний SSIM | Худший PCC | Худший SSIM | Медиана, мс |
|---|---:|---:|---:|---:|---:|
| Classical, 20 шагов | 0,4428 | 0,0350 | 0,2531 | 0,0155 | 150,3 |
| Classical, 200 шагов | 0,6383 | 0,2141 | 0,2569 | 0,0376 | 1476,2 |
| Neural | 0,6280 | 0,0652 | 0,2731 | 0,0374 | 10,2 |
| Hybrid, 20 шагов | 0,6214 | 0,2517 | 0,2679 | 0,0555 | 162,6 |

У Neural почти тот же средний PCC, что у 200 шагов Adam, при сокращении медианного времени примерно в 145 раз на этом GPU. SSIM Neural заметно ниже. Hybrid при равном с Classical бюджете в 20 шагов улучшил обе средние метрики. По сравнению с 200 шагами Adam у Hybrid выше средний и худший SSIM, а средний PCC ниже. Уточнение оптимизирует общий критерий, поэтому оно может снижать PCC даже при росте SSIM.

Отдельный прогон на Intel Core i5-12450H с четырьмя потоками дал медиану 71 мс для Neural, 462 мс для Hybrid с 20 шагами и 3,78 с для Classical с 200 шагами. Neural получил PCC 0,6280, Hybrid — 0,6213, Classical с 200 шагами — 0,6307. ## Воспроизведение

Из корня проекта с установленным backend и CUDA-сборкой PyTorch:

```sh
python -m doe.training.train --config configs/projected.json --device cuda --output runs/projected-repro
python -m doe.benchmark --checkpoint artifacts/doe-unet.pt --device cuda --samples 32 --output runs/comparison-repro
python -m doe --demo 0 --method hybrid --device cuda --output runs/example-repro
```

Замените путь к весам в бенчмарке на `runs/projected-repro/best.pt`, чтобы оценить собственный прогон. На CPU используйте `--device cpu`. Версии библиотек, аппаратная конфигурация и разбиение сохранены в JSON отчёта; время зависит от устройства и нагрузки.

Числа относятся к синтетическим целям и численному восстановлению. Данных с реального модулятора и отдельного набора изображений от организаторов для проверки обобщения не было.
