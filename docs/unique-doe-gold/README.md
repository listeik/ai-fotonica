# Эталон четырёхплоскостной ДОЭ

Локальный набор находится в `runs/unique-doe-gold-v1/`. Он содержит одну пару из четырёх целей 128×128 и одной общей 8-битной фазовой ДОЭ. Все девять основных PNG одноканальные. `target-1.png`–`target-4.png` идут по возрастанию расстояния, `doe.png` содержит фазу, `reconstruction-1.png`–`reconstruction-4.png` показывают результат распространения декодированной ДОЭ. Для переноса всего набора подготовлен `runs/unique-doe-gold-v1.zip`.

Набор создан прямым физическим синтезом. Сначала заданы непрерывная фазовая поверхность, сочетающая линзу, астигматизм, трёхлепестковую компоненту и две фазовые решётки, и четыре расчётные плоскости. Цели получены распространением непрерывной фазы в NumPy complex128. Затем фаза округлена до 256 уровней и восстановление выполнено заново из экспортированного PNG. Из 64 фазовых поверхностей выбрана поверхность с минимальным сходством между плоскостями с учётом энтропии. Попарный PCC целей составляет 0,146–0,222, энтропия изображений около 7 бит на пиксель.

Высокие метрики обусловлены физической согласованностью целей с общей фазовой поверхностью. Четыре изображения представляют каустические дифракционные узоры, полученные из одного известного решения. Они статистически зависимы через эту ДОЭ. Для четырёх заранее выбранных независимых рисунков результат той же величины здесь не продемонстрирован. Набор подходит для проверки оптического расчёта и формата экспорта, а также как один пример с известной фазовой меткой. Для обучения на разнообразных входах одного такого примера недостаточно.

Дополнительно выполнены 1500 шагов Adam с начальной аналитической ДОЭ, учётом квантования фазы и шагом обучения 0,001. Итоговый выбор сделан по минимуму PCC и глобального SSIM среди всех четырёх плоскостей после экспорта. Уточнение не улучшило этот критерий, поэтому сохранена аналитическая 8-битная ДОЭ. Это лучшее известное решение для данного набора среди проверенных кандидатов. Доказательство глобального оптимума отсутствует.

| Плоскость, мм | PCC | Глобальный SSIM | Локальный SSIM 7×7 | PSNR, дБ |
| ---: | ---: | ---: | ---: | ---: |
| 24,1 | 0,999873 | 0,999874 | 0,999823 | 53,49 |
| 25,3 | 0,999872 | 0,999875 | 0,999824 | 53,59 |
| 26,5 | 0,999880 | 0,999881 | 0,999832 | 53,31 |
| 27,7 | 0,999879 | 0,999877 | 0,999830 | 53,06 |

Оптическая модель соответствует проекту. Длина волны 532 нм, шаг ДОЭ 10 мкм, плоская волна единичной амплитуды, квадратная апертура 128×128 без дополнения нулями. Каждая цель расположена на нативной сетке своей плоскости. Код PNG переводится в фазу по формуле `φ = code × 2π / 255 − π`.

Входные изображения задают нормированную на максимум амплитуду `abs(U)`, как в существующем `export_phase`. В отчёте дополнительно приведено сравнение интенсивностей `abs(U)²`, для которого худшие PCC и SSIM также превышают 0,9999.

Проверка повторяет восстановление непосредственно из сохранённого `doe.png`, сверяет SHA-256 девяти PNG и воспроизводит цели из зафиксированных параметров. Независимая реализация распространения через прямые сепарабельные суммы Френеля в NumPy согласуется с NumPy FFT с относительной ошибкой амплитуды около 2,9×10⁻¹⁴. Разница с восстановлением PyTorch после округления составляет максимум один уровень PNG. Приведённые результаты относятся к принятой численной модели.

`manifest.json` фиксирует параметры поверхности, seed, физические параметры, версии библиотек, результат уточнения и хеши файлов. `metrics.json` хранит полный отчёт проверки, `design-search.json` перечисляет 64 кандидата, `preview.png` показывает цели и восстановление. Набор хранится отдельно от ранее подготовленных train, validation, test и OOD.

Для сборки в новый каталог и повторной проверки из корня проекта выполните следующие команды.

```powershell
.venv/Scripts/python.exe backend/scripts/prepare_unique_doe.py build --output runs/unique-doe-rebuilt
.venv/Scripts/python.exe backend/scripts/prepare_unique_doe.py verify
.venv/Scripts/python.exe backend/scripts/prepare_unique_doe.py package
```

Генерация полностью локальная. Внешние изображения и нейросетевые модели для этого набора не использовались.
